# Practical 5: Implement and compare RNN, LSTM, and GRU models for sequence classification, and analyze their performance using appropriate evaluation metrics.


## Aim

To implement and compare RNN, LSTM, and GRU models for sequence classification and analyze their performance using appropriate evaluation metrics.

## Description

In this practical, Recurrent Neural Network (RNN), Long Short-Term Memory (LSTM), and Gated Recurrent Unit (GRU) models were implemented for sequence classification using the IMDB movie review dataset. The models were trained to classify reviews as positive or negative and their performances were compared.

## Tools and Technologies Used

* Google Colab
* Python
* TensorFlow
* Keras
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Work Performed

* Loaded the IMDB movie review dataset.
* Preprocessed and padded the input sequences.
* Split the dataset into training and testing sets.
* Implemented an RNN model.
* Implemented an LSTM model.
* Implemented a GRU model.
* Trained all three models.
* Evaluated the models using accuracy, precision, recall, and F1-score.
* Compared the performance of RNN, LSTM, and GRU models.

## Result

The RNN, LSTM, and GRU models were successfully implemented and their sequence classification performances were compared using multiple evaluation metrics.
