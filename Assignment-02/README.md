# Practical 2: Design and implement a Multilayer Perceptron (MLP) for classification of the Iris or Wine dataset, and evaluate its performance using accuracy and a confusion matrix

## Aim

To design and implement a Multilayer Perceptron (MLP) for classification of the Iris dataset and evaluate its performance using accuracy and a confusion matrix.

## Description

In this practical, an MLP neural network was developed using TensorFlow/Keras to classify Iris flowers into their respective species. The dataset was preprocessed and divided into training and testing sets. The model was trained and evaluated using classification accuracy and a confusion matrix.

## Tools and Technologies Used

* Google Colab
* Python
* TensorFlow
* Keras
* NumPy
* Pandas
* Matplotlib
* Scikit-learn

## Work Performed

* Loaded the Iris dataset.
* Preprocessed and normalized the input features.
* Split the dataset into training and testing sets.
* Designed an MLP using Dense layers.
* Trained the MLP model using the training data.
* Evaluated the model using accuracy.
* Generated a confusion matrix to analyze classification performance.

## Result

The MLP model successfully classified the Iris flower species and its performance was evaluated using accuracy and a confusion matrix.
