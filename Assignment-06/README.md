# Practical 6: Design and implement a Convolutional Neural Network (CNN) for image classification using the Tomato or Soybean disease dataset.

## Aim

To design and implement a Convolutional Neural Network (CNN) for image classification using a plant disease dataset.

## Description

In this practical, a CNN model was developed using TensorFlow/Keras for image classification. The image dataset was preprocessed and divided into training and validation/testing sets. Convolutional, pooling, and fully connected layers were used to learn visual features and classify the images into their respective disease categories.

## Tools and Technologies Used

* Google Colab
* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib
* CNN

## Work Performed

* Loaded the plant disease image dataset.
* Resized and normalized the images.
* Divided the dataset into training and testing/validation sets.
* Designed a CNN architecture using convolutional and pooling layers.
* Added fully connected classification layers.
* Trained the CNN model.
* Evaluated the model using classification accuracy and loss.
* Visualized the training and validation performance.

## Result

The CNN model successfully learned image features and classified the plant disease images into their respective categories.
