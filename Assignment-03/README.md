# Practical 3: Implement forward propagation and backpropagation using TensorFlow/Keras. Analyze the effect of different learning rates and the number of epochs on model performance.

## Aim

To implement forward propagation and backpropagation using TensorFlow/Keras and analyze the effect of different learning rates and numbers of epochs on model performance.

## Description

In this practical, a neural network was implemented using TensorFlow/Keras. Forward propagation was used to generate predictions, while backpropagation was used to update the model weights based on the calculated loss. Different learning rates and numbers of epochs were tested to observe their effect on model performance.

## Tools and Technologies Used

* Google Colab
* Python
* TensorFlow
* Keras
* NumPy
* Matplotlib

## Work Performed

* Created a neural network model using TensorFlow/Keras.
* Implemented forward propagation through the network.
* Calculated the model loss.
* Applied backpropagation to update the weights.
* Experimented with different learning rates.
* Trained the model for different numbers of epochs.
* Compared the resulting model performance using accuracy and loss.

## Result

The effect of learning rate and number of epochs on neural network training and performance was analyzed successfully.
